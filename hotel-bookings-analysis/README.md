# Hotel booking cancellations

مشروع لتحليل إلغاءات الحجوزات الفندقية وبناء نموذج يقدّر مخاطر الإلغاء من معلومات متاحة وقت الحجز. البيانات تخص City Hotel وResort Hotel، وتشمل حجوزات من 2015 إلى 2017.

## الملفات

- `data/hotel_bookings.csv` — ملف البيانات المرفق.
- `src/analyze.py` — تنظيف البيانات، التحليل، تدريب النماذج، وحفظ الرسوم والمقاييس.
- `reports/report.html` — التقرير النهائي بصيغة مناسبة للعرض.
- `reports/report.md` — نسخة نصية من التقرير.
- `reports/metrics.json` — المقاييس الكاملة بصيغة قابلة للقراءة آليًا.
- `reports/*.png` — رسوم التحليل والتقييم.

## التشغيل

يتطلب Python 3.10 أو أحدث.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python src/analyze.py
```

## ملاحظات عن التحليل

الملف الأصلي يحتوي 119,390 صفًا. أزلت 31,994 صفًا متطابقًا بالكامل قبل التدريب، فبقي 87,396. بما أن الملف لا يحتوي معرّف حجز، لا يمكن الجزم إن كانت الصفوف المتطابقة نسخًا مكررة أو حجوزات مختلفة لها التفاصيل نفسها؛ لذلك يذكر التقرير معدل الإلغاء قبل التنظيف وبعده.

استبعدت من خصائص النموذج حالة الحجز النهائية وتاريخ تثبيتها، لأنهما يكشفان النتيجة بعد وقوعها. واستبعدت أيضًا نوع الغرفة المخصصة وتعديلات الحجز، إذ قد لا تكون معروفة عند إنشاء الحجز. الأرقام تقدير على تقسيم عشوائي واحد وليست ضمانًا للأداء في الاستخدام الفعلي.

## مصدر البيانات

تُعرف هذه المجموعة باسم Hotel Booking Demand. يصفها مصدرها البحثي بأنها سجلات حجوزات لفندقين في البرتغال بعد إزالة بيانات تعريف الفندق والعميل. [الورقة الأصلية](https://doi.org/10.1016/j.dib.2018.11.126).
