# Hotel_Booking_analysis
تحليل بيانات حجوزات فندقية وبناء نماذج لتقدير احتمالية الإلغاء باستخدام Python وScikit-learn. يتضمن المشروع تنظيف البيانات، تحليل الأنماط، مقارنة النماذج، وتقريرًا بالنتائج والقيود.  Topics: data-science · python · pandas · scikit-learn · machine-learning · hotel-bookings
